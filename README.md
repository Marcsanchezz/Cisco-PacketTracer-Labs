# 📡 Cisco Network Architecture & Packet Tracer Labs

Este repositorio contiene una serie de laboratorios prácticos de arquitectura de red e infraestructura diseñados en **Cisco Packet Tracer**, cubriendo desde la segmentación de Capa 2 hasta enrutamiento dinámico multisede e integración inalámbrica.

---

## 🚀 Proyectos Incluidos

### 1. 🎛️ Audio over IP (AoIP) - Red Básica
* Introducción a las redes de audio sobre IP y direccionamiento estático.
* Conexión punto a punto de dispositivos de red.

### 2. 🛡️ Segmentación L2/L3 y Seguridad con ACLs
* Configuración de **VLANs** (Venta e Ingeniería) y enlace **Trunking (802.1Q)**.
* Configuración de **Router-on-a-Stick** (Subinterfaces).
* Implementación de **ACLs Extendidas (Firewall)** para filtrado de tráfico por IPs de origen y destino.

### 3. 🌐 Servicios Centralizados (DHCP + DNS)
* Despliegue de **DHCP Centralizado** en router Cisco para asignación automática de direccionamiento por subred.
* Configuración de servidor **DNS local** para resolución de nombres de dominio de aplicación (`empresa.com`).

### 4. 🔄 Red Multisede Redundante (OSPF + Wi-Fi)
* Interconexión multisede (Madrid - Barcelona) mediante el protocolo de enrutamiento dinámico **OSPF (Área 0)**.
* Configuración de **Doble Enlace y Redundancia (Failover)** para tolerancia a fallos.
* Integración de red inalámbrica **Wi-Fi Corporativa** mediante Access Points e interfaces inalámbricas.

---

## 🛠️ Tecnologías y Protocolos Utilizados
* **Dispositivos:** Routers Cisco 2911, Switches Cisco 2960, Access Points, Servidores Web/DNS.
* **Protocolos de Enrutamiento:** OSPF v2 (Algoritmo Dijkstra).
* **Seguridad y Filtrado:** Access Control Lists (ACL Extendidas).
* **Servicios de Red:** DHCP, DNS, ICMP, ARP, 802.1Q (Trunking).
